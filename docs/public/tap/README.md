# Dialpad Tap — website

A customer-facing vision site for the Dialpad Tap hackathon proposal. The travel, healthcare, finance, and retail examples are illustrations; no live Dialpad agent or customer integration is connected. The “Tap to talk” button remains visible but is inactive until that flow exists.

Open `index.html` in a static server. All site paths are relative, so it can be served from a repository subdirectory.

This shareable copy excludes Season trial font files. It loads the Season Sans and Mix webfonts from Dialpad’s public website, which allows cross-origin font requests. It includes Dialtone color tokens under `DIALTONE_LICENSE.md`.
