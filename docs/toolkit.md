# Skills and tools

Find the help you need by what you want to accomplish.

- [Skills](/skills): workflows, when to use them, what they produce, and example requests.
- [Tools](/tools): the apps, connectors, and lookup tools that make those workflows possible.
- [Quick reference](/cheat-sheet): invocation syntax, launch commands, and common prompts.

If you are new, follow [Start here](/start-here) and continue through building, evaluating, and sharing. You do not need to study the whole catalog first.

## Skeptic review

`skeptic-review` provides a focused, read-only critical review. The relevant lenses can cover UI and accessibility, Dialtone adherence, data and state, security, compatibility, workflow safety, performance, test value, and scope.

For a readiness report before opening a PR, use `pr-prep`. It includes reviewer-first preparation and the app's final checks. [Skills and review decisions](/skills#reviews-and-your-decisions).

## Current inventory

Use `/skill-search` in Claude Code or `$skill-search` in Codex. It reads the current files rather than relying on a remembered list. The [Design repo](https://github.com/dialpad/design) contains shared skills and app-specific guidance.
