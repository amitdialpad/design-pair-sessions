# Design with AI

**Live site → https://amitdialpad.github.io/design-pair-sessions/**

A guide for Dialpad designers building and testing prototypes with Studio and Beacon. Agents handle implementation; designers frame the problem, direct the work, evaluate the result, and share it for feedback.

The main path is Start here → Build a prototype → Evaluate and iterate → Share your work. Skills, quick references, design process, and the original pair sessions live under Resources. Release updates and the Beacon Brief have their own Updates page.

The existing repository name and URL remain in use. Feed and newsletter automation writes to `docs/updates.md`; toolkit tracking writes to `docs/whats-new.md`. The homepage is the onboarding entry point.

## Running locally

```bash
npm install
npm run dev
```
